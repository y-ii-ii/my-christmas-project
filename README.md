# Merry Christmas WebGL

一个以圣诞树为主题的交互式 3D 网页动画。项目使用 Three.js 在浏览器中呈现由彩灯、飘雪、星空和照片装饰组成的圣诞场景；张开手掌可以让树形粒子绽放成星云照片墙，握拳则恢复为圣诞树。

> 当前照片和音乐素材已移除。项目可以在没有这些素材时启动；添加自己的图片和音乐后即可启用对应内容。

## 功能

- WebGL 圣诞树、旋转彩灯、飘雪、星空和辉光效果。
- 照片沿圣诞树螺旋排列，并可展开为环绕式照片墙。
- 可选手势控制：摄像头识别张开手掌和握拳手势，用于展开、旋转和收拢动画。
- 可选背景音乐；缺少音乐文件时显示提示，不影响场景运行。

## 环境要求

- Node.js（建议使用当前维护中的 LTS 版本）
- 支持 WebGL 的现代浏览器
- 如需手势控制，需使用 localhost 或 HTTPS，并允许浏览器访问摄像头

## 本地运行

```bash
npm install
npm start
```

打开终端显示的本地地址（默认 `http://localhost:3000`）。生产构建：

```bash
npm run build
```

## 添加照片和音乐

- 照片：将 `.jpg`、`.jpeg`、`.png` 或 `.svg` 文件放入 `src/assets/photos/`。保存后重启开发服务器以加载新增照片。
- 音乐：将背景音乐命名为 `bgm.mp3` 并放入 `public/music/`。刷新页面后，右下角音乐控制会启用。

请确保添加的照片和音乐拥有合适的使用与分享授权。大体积或不适合公开的个人素材请勿提交到公开仓库。

## 手势操作

1. 点击右上角 **START CAMERA** 并允许摄像头访问。
2. 张开手掌：将圣诞树展开成星云照片墙；照片墙展开时，左右移动手掌可调整旋转。
3. 握紧拳头：将场景恢复成圣诞树。

相机控制是可选功能，也可以直接通过鼠标拖动旋转场景。
